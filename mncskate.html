MNC-SKATE / Modular Park System

Build the whole spot.

MNC-SKATE is more than a board. We are developing a modular skatepark platform built around 3D-printed obstacles that can be mixed, moved, collected and expanded. The idea is to let the user build a personal miniature spot the same way a skater sees a city.

Why MNC-SKATE?

We want to treat fingerboarding with the same attention given to full-size skate products: graphics, hardware, packaging, park architecture and community. MNC-SKATE connects MENOCLONE's art direction with product prototyping and maker culture.

The first phase is intentionally small: build physical samples, test them, document the process, improve the parts, and create a founders-era release around the people who helped shape it.
